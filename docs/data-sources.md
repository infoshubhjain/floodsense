## Source status checked

- FEMA’s REST directory returned service version 11.1 and layer 28 metadata with EPSG:4269, flood-zone feature geometry, and the four requested fields. A live query around Minneapolis returned actual FEMA features, including Zone X and AE.
- FEMA NFHL is the effective mapped layer. Its effective dates are maintained by the map panels; this feature-layer response does not provide one national effective date. Use the [FEMA Map Service Center](https://msc.fema.gov/portal/home) to check a panel.
- The Census API documentation describes single-record address lookup, `Public_AR_Current`, and the address-range nature of returned coordinates. It also states that the benchmark may change.
- No elevation service, depth raster, rainfall feed, or historical event layer is integrated. Terrain alone would not provide a flood model, and optional sources were excluded until their semantics were needed and verified.

## Update procedure

1. Recheck the official endpoint, API schema, output CRS, fields, feature cap, update behavior, and current terms in the source’s primary documentation.
2. Record the access date and relevant changes in this ledger; do not change attribution or cache behavior by assumption.
3. Test the service response and a small reference AOI. Update fixtures/tests and the displayed metadata if field meanings, geometry behavior, or dates change.
4. Keep the no-silent-substitution behavior and synthetic label intact when the provider is unavailable.
